I repeated the HTML layout for all the pages essentially. The site pages all shared the same HTML document structure and for the most part the same exact nesting. This made it really useful when I started linking CSS layouts for each page, because I could switch out layout or modify layouts and change the way the document looks without going back to edit the HTML. Links broke when I moved files around. Making sure that all the files were linked properly turned out to be the culprit for most buggy behavior or for when a page did not layout the way I expected it to. I think a web component that I would like a tool to generate for me would be forms, and other form adjacent inputs. I feel like it can get quite tricky when theres multiple options/types of input required along with making sure all the necessary buttons/labels/other features are connected properly. I think also generally having a tool that can generate headers/footers would be really useful because those build out of a ready template most of the time. They certainly have on this assignment. It was very interesting working on this assignment by copying templates around and keeping everything structured and nested in their respective folders. I feel like this has made this code to be very concise, readible, and most importantly of all very adjustable. I think that anyone can open the source files and would really only need to change the values in each pages CSS file to implement the design choices they are looking for.
